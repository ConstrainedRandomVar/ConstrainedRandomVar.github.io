# constrainedrandomvar.github.io

Root of the GitHub Pages address. `index.html` forwards to the अध्ययन-सहकारी site
(https://constrainedrandomvar.github.io/adhyayana-sahakari/). This repo also holds Google Search Console's
site-ownership file (`google<token>.html`), needed for Google OAuth brand verification of the site's
Drive-sync sign-in. Do not delete that file.

The project sites (adhyayana-sahakari, vedantic-vyakarana-academy, prasthanatrayi-search, …) live in their own
repos and are unaffected by this one.
